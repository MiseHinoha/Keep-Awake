# 合盖保活（KeepAwake）安装说明

一个顶栏小工具：**让 MacBook 合上盖子也不休眠**。
适合合盖后还要远程连回来、或者跑着长时间任务的场景。

---

## 先说清楚它是什么

- 它做的事只有一件：切换 macOS 的 `pmset` 开关 `SleepDisabled`。
  打开后合盖、锁屏、屏幕关闭都不会睡。
- **不联网、不上传任何东西**，没有后台服务，没有账号。
- 需要 **Apple Silicon（M 系列芯片）+ macOS 13 或更高**。Intel 的 Mac 装了跑不起来。

## 安装

1. 把 `KeepAwake.app` 拖进「应用程序」文件夹。
2. 第一次打开如果被系统拦下（提示「无法验证开发者」）：
   打开 **系统设置 → 隐私与安全性**，往下滚到「安全性」，点 **仍要打开**，再确认一次。
   > 之所以会被拦：这个 app 没有买 Apple 的开发者签名（一年 99 美元那种），
   > 用的是本机自签名。功能不受影响，只是首次需要你手动放行。

3. **一次性授权**（可选但强烈建议）：
   点顶栏的图标 → 菜单里会弹出一行命令，复制到「终端」里跑一次，输入你的登录密码。
   之后切换开关就再也不问密码了。
   不想跑也行 —— 那样每次切换都会弹一次系统密码框。

## 怎么用

- 点顶栏的图标 → 切换开/关。**图标本身就是状态**：关着是月亮，打开后变成橙色的咖啡杯。
- 打开后：合盖、锁屏、黑屏都不会睡，SSH / 远程桌面 / 后台任务都能继续跑。

## 别忘了关掉

**开着的时候它真的不睡**，所以：

- 放在包里、用电池的时候请务必关掉 —— 不然它会一直跑，又热又费电。
- 长期插电用可以一直开着。

## 卸载

1. 顶栏菜单里关掉开关，然后选「退出」。
2. 从「应用程序」里把 `KeepAwake.app` 删掉。
3. 如果做过第 3 步的一次性授权，想一并撤销就再跑一次终端：

   ```sh
   sudo rm /etc/sudoers.d/keepawake /usr/local/sbin/keepawake-pmset
   ```

---

## 关于安全

这个 app 没有 Apple 公证签名，所以系统会提示"无法验证开发者"。
如果你想确认它没做别的事，可以看它的源码 —— 一共就三个 Swift 文件：

- `Sources/Core/PowerState.swift`：读系统状态、判断该做什么（纯函数，好读）
- `Sources/App/main.swift`：顶栏菜单与状态同步
- `Sources/App/StatusIcon.swift`：顶栏那枚图标怎么画

它切换开关的方式是调用 `/usr/local/sbin/keepawake-pmset on|off` 这个脚本，
脚本里只有一行 `pmset -a disablesleep`。授权用的是 sudoers 白名单，
**只放行 `on` 和 `off` 两个参数**，别的参数一律拒绝。
